# Plantilla Inmobiliaria A

Plantilla web reutilizable para empresas inmobiliarias. Está integrada al editor de sitios de Gavrion y consume la configuración de la empresa desde `site-config.js`.

El editor permite personalizar identidad visual, portada, SEO, contacto, catálogo de propiedades, ubicación, redes, galería, CRM y chatbox. La copia de cada empresa se guarda como proyecto independiente y la plantilla maestra no se modifica.

El proyecto de referencia `m2-inmobiliaria` aporta la arquitectura funcional de propiedades, solicitudes, equipo, CRM y configuración. Sus credenciales, usuarios y datos de Supabase no se incluyen en esta plantilla portable.
