# Plantilla Gastronomía A

Esta carpeta forma parte de `nexo-crm-next` y contiene la plantilla web portable de gastronomía.

- `index.html`: estructura visual.
- `styles.css`: diseño responsive.
- `site-config.js`: identidad, contenido, menú e integraciones editables por cliente.
- `app.js`: comportamiento del menú, pedido, QR y conexión opcional con el chatbox real.

Vista previa local/desplegada: `/templates/gastronomia-a/index.html`.

El editor del implementador deberá modificar una configuración por empresa y generar una copia entregable; no debe modificar directamente la plantilla maestra.
